# 03｜首页与移动端UI：三视图信息架构

日期：2026-08-24  
范围：首页、金价、油价三视图与底部导航，不含趋势图

## 页面边界

一级视图固定为：首页、金价、油价

- 品牌金价归入金价视图，不单独作为一级页
- 首页只承载日常总览，保留最常看的金价和油价摘要
- 金价趋势、油价变动趋势分别预留在金价、油价页后续区域，本轮不渲染占位图、入口或空卡片
- 98号汽油没有可靠报价，不在任一视图显示
- 切换只在当前页面内切换视图，不引入路由框架；三个视图共用一次读取到的展示数据

## 全局框架

页面由三部分构成：固定顶部栏、可滚动内容区、固定底部导航

### 顶部栏

- 左侧：当前视图标题。首页为「日常行情」，金价为「金价」，油价为「广东油价」
- 首页可显示副标题「广东 · 日常价格」；金价、油价页不重复堆叠说明文字
- 右侧：`刷新显示`按钮。只重新读取本地展示数据，不能触发采集
- 读取中按钮文案为「正在读取」，禁用重复点击
- 读取失败时，在顶部状态提示区显示「未能读取本地展示数据」，保留上次已成功显示的内容

### 内容区

- 采用单列卡片，宽屏最大内容宽度保持现有约束
- 内容区底部留出底部导航高度、设备安全区和16px间距，末项不可被导航遮挡
- 所有价格项沿用`current`、`cached`、`unavailable`三种独立状态；每项自身状态决定价格、徽标和说明，不能由同卡其他项代替

### 底部导航

底部导航固定于视口底部，顺序为：

| 视图 | 标签 | 图标建议 | 激活状态 |
| --- | --- | --- | --- |
| 首页 | 首页 | 简洁房屋轮廓 | 金色或深绿色图标与文字、顶部2px强调线或浅色底 |
| 金价 | 金价 | 金币或金条轮廓 | 同上 |
| 油价 | 油价 | 油滴或加油枪轮廓 | 同上 |

- 每个导航项均为`button`，不依赖链接路由
- 单项最小点击尺寸44×44px，三项等宽，各自的实际触控区域覆盖整块导航项
- 当前项使用`aria-current="page"`，非当前项不带该属性
- 图标只做辅助，标签文字始终可见；不能仅依靠颜色区分激活状态
- 视图切换后内容区滚动回顶部，焦点移到当前视图的`h1`或主内容标题，避免键盘和读屏用户停留在已隐藏内容
- 使用`hidden`或等效不可访问状态隐藏非活动视图，不能只以视觉样式遮挡

## 首页：价格摘要

首页首屏目标是在360px宽度看到金价摘要完整主卡、品牌摘要首行，以及92、95号油价主块

### 金价摘要

顺序固定如下：

1. 国际黄金人民币折算，主价格，元/克
2. Au99.99，主价格，元/克
3. 国内外价差，同时显示元/克和百分比
4. 国际黄金XAU/USD，次级信息，USD/盎司

卡片组织：

- 折算价与Au99.99位于摘要主卡的两块主数值区域。360px下各占一半，数字和单位不拆行
- 国内外价差占整行，价差数值和百分比在同一行优先；空间不足时百分比换至下一行
- XAU/USD置于价差下方的次级行，字号和对比度低于两项主价格，但状态与行情时间仍完整
- 同一张卡内可以存在混合状态，例如折算价为当前有效、Au99.99为缓存数据

### 品牌金价摘要

- 节标题为「品牌金价」，副注为「足金饰品，元/克」
- 固定顺序：周生生、周大福、六福、老凤祥
- 采用紧凑四行列表：左侧品牌名，右侧价格；状态、行情时间缩为价格下方或整行次级文字
- 首页不显示品牌品类、来源名称，避免摘要卡过长；这些字段进入金价页

### 油价摘要

- 节标题为「广东油价」，副注为「官方最高零售价」
- 92号、95号为等权双列主块，分别展示元/升、状态与当前生效时间
- 0号柴油不作为首页主要内容。可不在首页显示；若显示，只能在92、95主块下以次级单行呈现
- 油价生效时间以该油品的`effectiveFrom`为准，多个油品相同可在卡片底部合并展示一次，存在差异时逐项显示

## 金价页：完整金价信息

金价页按「国际与国内参考」和「品牌金价」两节组织

### 国际与国内参考

固定展示以下五项：

| 项目 | `assetId` | 视觉层级 | 用户可见字段 |
| --- | --- | --- | --- |
| 国际黄金XAU/USD | `xau-usd` | 次主项 | 名称、价格、USD/盎司、状态、行情时间、来源 |
| USD/CNY | `usd-cny` | 次主项 | 名称、价格、汇率单位、状态、行情时间、来源 |
| 国际黄金人民币折算 | `international-gold-cny-gram` | 主项 | 名称、价格、元/克、状态、行情时间、来源或派生说明 |
| Au99.99 | `au9999` | 主项 | 名称、价格、元/克、状态、行情时间、来源 |
| 国内外价差 | `domestic-international-gold-spread` | 主项 | 名称、元/克、百分比、状态、行情时间、派生说明 |

- 折算价、Au99.99、国内外价差优先置顶，XAU/USD、USD/CNY放入同一张参考卡的次级区域
- 派生项可以标明「根据国际黄金与汇率计算」或「根据Au99.99与国际折算价计算」，但不展示`derivedFromIds`、采集时间等内部字段
- 来源只展示简短来源名；缓存状态独立显示为「缓存数据」，来源不能替代状态

### 品牌金价

固定顺序：周生生、周大福、六福、老凤祥

每个品牌行或卡片展示：

| 字段 | 说明 |
| --- | --- |
| 品牌 | 周生生、周大福、六福、老凤祥 |
| 品类 | 使用记录中的可靠品类文本；无可靠品类时显示「足金饰品」而非臆造具体规格 |
| 价格 | 元/克，`unavailable`时替换为「暂无可靠数据」 |
| 报价时间 | `observedAt`，只显示记录实际具备的日期或日期时间精度 |
| 来源 | 简短来源名称，不展示采集技术细节 |
| 状态 | 当前有效、缓存数据或不可用 |

- 品类、来源、状态、报价时间可在价格下方的两行辅助信息中排列，360px下允许自然换行
- 缓存项仍显示其原始报价时间和来源，并追加「缓存数据」徽标
- 无可用数据项保留品牌名称、品类和「暂无可靠数据」，不显示虚构单位、时间或来源

## 油价页：完整广东油价

油价页以一张主列表或三张轻量卡片展示：92号汽油、95号汽油、0号柴油

| 项目 | `assetId` | 视觉层级 | 用户可见字段 |
| --- | --- | --- |
| 92号汽油 | `guangdong-fuel-92` | 主项 | 名称、元/升、状态、当前生效时间、来源 |
| 95号汽油 | `guangdong-fuel-95` | 主项 | 名称、元/升、状态、当前生效时间、来源 |
| 0号柴油 | `guangdong-fuel-0-diesel` | 次项 | 名称、元/升、状态、当前生效时间、来源 |

- 92、95保持并列主块，0号柴油在下方次级行或独立次级卡
- 「当前生效时间」优先采用`effectiveFrom`。该字段没有时才使用可靠的`observedAt`并标为「行情时间」，不能把`collectedAt`展示为生效时间
- 同一调价公告下的三项可在列表末尾合并显示一条「当前生效：M月D日」，前提是三项`effectiveFrom`完全一致
- 98号汽油不显示空行、不显示「暂无可靠数据」提示，避免为不存在的可靠报价占据页面空间

## 状态与字段规则

| 状态 | 价格区域 | 时间与辅助信息 |
| --- | --- | --- |
| `current` | 展示可靠当前有效价格 | 徽标「当前有效」；展示行情时间或油价生效时间与来源 |
| `cached` | 展示最后成功缓存价格 | 徽标「缓存数据」；展示原始行情时间或生效时间与来源，可补充「当前采集暂不可用」 |
| `unavailable` | 展示「暂无可靠数据」 | 徽标「不可用」；显示安全的简短原因或「暂未取得可靠数据」 |

- 所有页面只将`observedAt`、油价`effectiveFrom`当作面对用户的行情时间
- `collectedAt`、原始响应、派生追溯ID保留给数据层，不进UI
- 国内外价差百分比只读取展示层已提供的可靠字段；字段缺失时显示「百分比不可用」，不由前端反推
- 金额、汇率、小数和单位按资产既有格式展示；不可用状态不显示0、`--`或推算替代值

## 360px、393px验收点

1. 360px与393px下页面无横向滚动，底部导航不遮挡末项内容
2. 首页金价摘要中两项主价格清晰可读，价差元/克与百分比不重叠，XAU/USD视觉层级明显较低
3. 首页四品牌摘要保持四行，名称、价格、状态和时间不相互覆盖；92、95双列主块可读
4. 金价页五项参考数据与四个品牌都能展示独立状态。品牌辅助字段换行后不截断价格或状态徽标
5. 油价页92、95、0号柴油均能显示当前生效时间。98号没有任何价格或空白占位
6. 缓存项显示低饱和「缓存数据」徽标，不使用错误色；不可用项显示「暂无可靠数据」且不带假价格
7. 刷新显示期间按钮禁用且文案准确。读取失败后已显示价格仍保留，初次读取失败才显示整页空状态
8. 底部三个导航项均有44×44px以上点击区，当前项有文本和视觉双重状态，键盘焦点可见
