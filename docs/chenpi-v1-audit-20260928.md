| 媒体不同取价方式未分清 | 信息时报为实地走访零售观察；健康时报为行业指导价转述；大公报为历史媒体价格表。现有价格没有独立经销商采访价或有自身有效日期的历史价目，不虚构类别或日期 |
| 2025表格与2026资料视觉混排 | 12条2025历史媒体表独立收折区，与2026媒体资料、挂牌分层 |

| 显著价格差只藏于单条备注 | 两处价格差异提示，保留来源并列，不取均值、统一区间、村排名或推断涨跌 |
| 指导价转述可能被当已核官方价 | 明示原协会公告、采价方法待核，降低权重，仅为媒体转述资料，非官方指数、当前有效价或成交价 |
| 商品年限证据仅有备注 | 独立字段显示晒制时间、商称年限、性质未明年标、字段／版本冲突；不按年份相减认定足年 |
| 生源旧十年报价与实时页面不同 | 原10年380.9元/500克留在审查记录，本轮5年380元并列记录；不覆盖旧记录或选一个消解冲突 |
| 罗立荣和家业只读旧检索页 | 本轮直达超时，标实时核验受限，移出主参考，不称仍挂牌、有效、下架或售罄 |
| 商品规格与起购量混写 | 独立包装规格与起购量；有赞两条起购量均未披露，不把50克／250克规格当MOQ |
| 元/斤显著展示掩盖小包装成本 | 商品原报价及规格优先，元/斤为弱化辅助换算，注明不是斤装售价 |
| 品牌小包装与散装供应混排 | 四村各自分供应／批发、普通零售、品牌小包装三层，无数据显暂无，不形成统一区间 |
| 报价日期与页面核验未同时保存 | 原始报价时间未知保留空值，单列截至2026-09-28的页面核验状态、购买入口及库存证据 |
| 没有主参考的排除规则 | 售罄、下架、冲突、未核验及无法换算的样本不进入主参考，保留可展开的排除记录 |
| 同商家商品可能被误当独立来源 | 罗立荣东甲／天马来自同一页同一商家，仅为两个商品规格观察，不计两个独立商家 |
