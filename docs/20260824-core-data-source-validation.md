- Currency Exchange Tool在2026-08-24连续两次返回同一报价6.7225，均带`updatedAt=2026-08-24T07:59:51.718Z`和24小时变动字段。

### 广东油价

- 英德市政府转载的广东省发展改革委公告`https://www.yingde.gov.cn/zwgk/tzgg/content/post_2177771.html`明确，2026-08-14 24:00起执行的广东最高零售价为：92号汽油7.80元/升、95号汽油8.45元/升、0号柴油7.45元/升。
- 该公告署名来源为广东省发展改革委，包含完整生效时刻和价格表，可正式作为当前有效公告来源。
- 98号汽油未出现在该公告表中，保持未解决，不计算也不推算。
- 自动获取的最小规则：从广东省发改委站点及其市级政府转载公告中，选择标题和正文均含成品油调价、且`effectiveFrom`最大的已生效公告；缺少三个目标油品中任一项时仅展示已明确的油品。

### 金价与价差

- XAU/USD必须同时含数值、来源、行情时间；行情时间不属于中国当日或来源标记陈旧时不可用。
- USD/CNY使用Currency Exchange Tool作为暂定主源；官方中间价和Frankfurter保持参考用途。
- 国际金价人民币克价：`XAU/USD × USD/CNY ÷ 31.1034768`。
- 国内外价差：`Au99.99 − 国际金价人民币克价`。派生记录保存两条输入记录ID、输入来源、输入时间、计算时间和换算常量。
- 两个输入任一不可用、过期或时间差超过后续确定阈值时，派生金价与价差均不可用。

### 品牌金价

- 官方源优先；可靠第三方可做主源候选或交叉核验源。
- 每条记录必须有品牌、品类、报价、单位、适用市场、报价日期或时间、来源URL和采集时间。
- 第三方数据缺少报价时间，或无法通过品牌官网、官方旗舰店、另一独立来源验证时，不进入V1展示。
- 不使用估算价、推算价或聚合均值。

- 保存公告URL、发布日期、采集时间、生效时刻及92、95、98号汽油和0号柴油的最高零售价。
