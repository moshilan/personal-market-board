# 03｜首页与移动端 UI 规格

日期：2026-08-24
范围：首页最小版本；面向个人及家人手机日常查看。

## 目标与边界

- 进入首页后，首屏优先读到黄金四项、品牌金价和广东92/95号油价。
- 页面只读取展示快照。`刷新显示`仅重新读取本地展示数据，不能触发采集，因此不使用“刷新行情”“更新行情”等文案。
- 使用`buildDisplaySnapshot`的观察记录：`displayStatus`为`current`、`cached`或`unavailable`；用户可见的时间只取`observedAt`（油价为`effectiveFrom`归入该字段），绝不展示`collectedAt`为行情时间。
- 无可用值时展示不可用，不显示`0`、`-- 元/克`或由其他价格推算出的替代值。
- 首版不含图表、换汇、自动轮询、分类页、账户、设置或复杂离线缓存。PWA仅含manifest、图标和可安装声明；不增加Service Worker数据缓存策略。

## 页面结构

页面为一列，内容容器最大宽度`640px`，在宽屏时居中；移动端按下列顺序排布：

1. **顶部栏**：标题“行情看板”、副标题“广东 · 日常价格”；右侧`刷新显示`按钮。按钮仅图标时必须有可见文字或`aria-label`，首版采用文字按钮以减少误解。
2. **黄金**：节标题“黄金”。一张主卡：
   - 首行大号`国际黄金 XAU/USD`；
   - 中间两项并列（窄屏仍保持各占半宽）：`国际黄金折算`与`Au99.99`，均为元/克；
   - 底部横向/自动换行的`国内外价差`，同时显示“+/- N.NN 元/克”和“+/- N.NN%”。
3. **品牌金价**：节标题“品牌足金”，副注“元/克”。一张列表卡，固定顺序：周生生、周大福、六福珠宝、老凤祥。每行左为名称，右为加粗价格和单位，下一行或右下角放状态与行情时间。
4. **广东油价**：节标题“广东油价”，副注“元/升”。92号、95号使用两个并列主块；`0号柴油`为同卡下方的次级行。98号汽油不进入首页；即使记录存在也不渲染。
5. **页脚**：简短说明“价格以各数据源行情时间为准”，不堆叠来源URL、采集细节或投资提示。

所有价格项均使用相同的展示字段：名称、价格（含货币/单位）、状态、行情时间。来源、派生追溯ID和采集时间保留在数据中但不进入首页。

## 状态与文案

状态是每项独立的，不能因为同一张卡内另一项可用而掩盖其状态。

| `displayStatus` | 徽标文案 | 说明文案 | 价格区 |
| --- | --- | --- | --- |
| `current` | `当前有效` | `行情时间：M月D日 HH:mm`（仅日期精度时只显示日期） | 正常显示 |
| `cached` | `缓存数据` | `行情时间：M月D日 HH:mm`；可在卡片底部补充“当前采集暂不可用” | 正常显示，使用缓存色徽标 |
| `unavailable` | `不可用` | 优先显示`reason`的简短安全文案，否则“暂未取得可靠数据” | 显示“暂无可靠数据”，不显示单位 |

`cached`不是报错：使用低饱和浅黄色徽标和文字提示，不用红色、警告图标、弹窗或整卡遮罩。`unavailable`保持中性灰，以清晰性优先；不把“未连接服务”这种技术故障文案暴露给家人。

点击`刷新显示`期间：按钮文案变为“正在读取”，设置`aria-busy="true"`与禁用态；读取成功后恢复“刷新显示”。读取失败时，在顶部状态区域显示“暂时无法读取本地展示数据”，保留上一次成功渲染内容；页面初始且无内容时才显示整页空状态“暂时无法读取数据”。

## 无障碍与交互

- 正文对比度至少4.5:1；仅靠颜色不能表达状态，徽标必须包含上述文字。
- 所有交互目标最小`44 × 44px`。`刷新显示`可见区域至少`44px`高，焦点环使用`2px solid #185FA5`且不被裁切。
- 使用语义化`header`、`main`、`section`、`article`和`button`；每个节标题关联对应区域。状态通过可读文本呈现，不以纯图标代替。
- 价格更新用`aria-live="polite"`的简短状态区提示，不应让屏幕阅读器逐项重复整页数字。
- 时间由ISO字段按中文本地格式化；无时区信息或仅日精度时，不虚构具体时分。
- 支持系统字体与用户放大文本；内容区、状态徽标和单位可换行，价格数字不可截断。遵循`prefers-reduced-motion`，首版不添加非必要动画。

## PWA最小要求

- `manifest.webmanifest`包含应用名称、短名称、`display: standalone`、`start_url: /`、`theme_color`和`background_color`。
- 提供可缩放SVG图标；图标使用简洁金色圆点/价格牌图形，不暗示实时交易。
- HTML引用manifest和iOS基础meta（`apple-mobile-web-app-capable`、状态栏颜色）。如浏览器要求Service Worker才能显示安装入口，可注册只负责安装激活、没有`fetch`处理器的最小脚本，不缓存页面或市场数据。

## 验收视觉检查

在`360px`和`393px`宽度检查：首屏中黄金完整、品牌卡首行和92/95主块可见；左右无横向滚动；数字、状态和时间均不重叠。另以三组展示快照验证：全为`current`、成功缓存为`cached`、无缓存为`unavailable`。同一页面可混合三种状态，且每一项均按自身状态显示。
